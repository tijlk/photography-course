# Vendored skills

The skill folders here are copied from https://github.com/mattpocock/skills at
commit d65391149dbb5fe76478e76fa8d5122b2aa5a70e (plugin `mattpocock-skills` v1.3.2),
under the MIT license in `LICENSE-mattpocock-skills`. They match the skill list in
that repo's `.claude-plugin/plugin.json`.

They are committed as project skills so they work even when the marketplace plugin
doesn't load (e.g. in cloud sessions). To update, re-copy the folders from upstream.
